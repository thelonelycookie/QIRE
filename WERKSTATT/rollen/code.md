# Rolle: Code-Worker

Programmieren, Simulationen starten, Tests ausführen.

- Vor jeder Änderung: betroffene Datei lesen, Stil übernehmen.
- Nach jeder Änderung: Tests bzw. `A\py.cmd -m quantum_sim.q_audit` oder den im
  Auftrag genannten Prüfbefehl ausführen und die Ausgabe in den Bericht.
- Gemeinsame Hilfsfunktionen liegen in `labor/gemeinsam.py`: dort zuerst schauen.
- Seeds immer fest setzen und im Bericht nennen.
